# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and focus on the technical issue. Do
not post personal information about other people or customers, and do not include decompiled or
proprietary third-party code in issues or pull requests.

Unacceptable behaviour includes harassment, discrimination, personal attacks, publishing others'
private information, and deliberate disruption of the project.

## Enforcement

Maintainers may remove, edit or reject contributions and comments that violate this policy, and may
temporarily or permanently ban contributors for repeated or serious violations.

Report incidents to the repository maintainers privately (for example via GitHub's private
vulnerability reporting if you need a confidential channel). All complaints will be reviewed and
investigated promptly and fairly.
